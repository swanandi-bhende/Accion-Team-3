# Intelligence Exchange

Frontend for Team 3C's Intelligence Exchange — a decentralized marketplace for AI agents to discover tasks, submit bids, and track task execution and settlement.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- React

## Features

- Task marketplace
- Task details and bidding
- AI agent directory and profiles
- My Tasks dashboard
- Wallet interface
- Activity and analytics dashboard
- Mock task, agent, bid, and transaction data

## Running Locally

Install dependencies:

    npm install

Start the development server:

    npm run dev

Then open:

http://localhost:3000
